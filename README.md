# 💊 MindPill

A playful concept landing page for **MindPill** — the fictional magic pill that installs Claude in your mind.

Single-page static site (HTML + CSS, no build step), hosted on **GitHub Pages**.

## Live site

Once Pages finishes building: `https://ayoubbassou-sketch.github.io/mind-pill/`

## Local preview

Just open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Edit

Everything is in [`index.html`](index.html) — copy, colors (CSS variables at the top), and sections. Make it yours.

## Disclaimer

MindPill is a fictional product built as a demo. It is not affiliated with Anthropic. No actual pills are involved.
